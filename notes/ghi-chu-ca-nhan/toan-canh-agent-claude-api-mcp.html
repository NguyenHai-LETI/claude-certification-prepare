#Chuyện gì xảy raAi làm
1Người dùng gửi yêu cầu, ví dụ "ticket T-123 khách hỏi gì?", tới backend của bạn. Backend xác thực user rồi giao cho harness.Server của bạn
2Harness gửi POST /v1/messages gồm system, tools và toàn bộ messages. Request nào cũng gửi lại đủ, vì API không nhớ gì giữa các request.Harness
3Claude API chuyển cho model. Model chỉ đọc mô tả tool, không thấy code, rồi quyết định trả lời luôn hay xin gọi tool.Anthropic
4Response quay về với stop_reason: "tool_use" và khối tool_use, ví dụ read_ticket({"ticket_id":"T-123"}). Model không tự chạy tool.Anthropic → harness
5Tool là custom tool: harness gọi hàm của bạn, hàm đọc DB hoặc API nội bộ. Kết quả được gửi lại ở bước 2 dưới dạng tool_result. Lặp lại đến khi model trả end_turn.Harness
6Tool là tool MCP: harness chuyển lời gọi cho MCP client. MCP client gọi MCP server Google Drive hoặc Salesforce, và MCP server mới gọi API thật của dịch vụ.Harness + MCP server
7Code execution với MCP: thay vì gọi từng tool, model viết một đoạn code. Sandbox chạy code đó, và code gọi các hàm bọc MCP. Dữ liệu lớn đi từ Drive sang Salesforce trong sandbox, chỉ dòng log quay về model.Harness (sandbox)
8Server tool như web_search: Anthropic tự chạy ngay trong lượt đó. Harness không phải làm gì, kết quả nằm sẵn trong response.Anthropic
9MCP connector: khai báo mcp_servers trong request, Claude API tự gọi MCP server remote như Jira. Không cần MCP client trong harness. Chỉ dùng được với server remote công khai, không dùng được với server local qua stdio.Anthropic + MCP server
Cốt lõi. Model chỉ đọc và quyết định. Việc chạy tool là của harness (custom tool, MCP qua client, sandbox), hoặc của Anthropic (server tool, MCP connector). Mọi thứ model "thấy" đều phải đi qua context, nên bớt tool thừa và giữ dữ liệu trung gian ngoài context là hai cách tiết kiệm token chính.

4. Harness nằm ở đâu, tùy cách xây agent

Cách xâyAi viết vòng lặpAi host harness và chỗ chạy tool
Messages API, tự viết vòng lặpBạnBạn (đúng như sơ đồ)
Tool Runner trong SDK AnthropicSDK, bạn chỉ viết hàm toolBạn

Claude Code cũng là một harness: nó chạy trên máy bạn, gửi request tới Claude API, tự chạy Read, Edit, Bash và gọi MCP server bạn cấu hình.
