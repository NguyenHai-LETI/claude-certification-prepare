Hình dung đời thường
Bạn vào một nhà hàng. Thực đơn là danh sách những gì bếp làm được. Bạn (khách) gọi món, bếp nấu rồi bưng ra. Có món cần nấu (hành động), có món chỉ cần lấy từ tủ lạnh ra (đọc dữ liệu), có combo dựng sẵn bạn chọn từ menu (mẫu prompt). MCP server là cái bếp: nó công bố nó làm được gì, rồi làm khi được gọi.

2.1 What Is MCP and Why Does It Matter? (Bài 1)

MCP (Model Context Protocol) là giao thức chuẩn hóa cách LLM giao tiếp với external tools và data. Thay vì tự viết integration riêng cho từng service, bạn kết nối Claude với bất kỳ MCP server nào — dù là Linear, GitHub, hay database nội bộ — bằng cùng một API.

Kiến trúc: MCP Host (Claude Desktop, Claude Code) → MCP Client (tích hợp trong host) → MCP Server (chạy external service).

Có hai loại server: Local (stdio transport, chạy cùng máy, dùng cho file systems, local CLI) và Remote (SSE hoặc StreamableHTTP, chạy trên server, dùng cho SaaS APIs như Linear, Slack).

Transport là kênh chở thông điệp giữa client và server. Với stdio, client tự khởi chạy server như một tiến trình con rồi nói chuyện qua stdin/stdout. Với HTTP, server đã chạy sẵn ở xa và client gọi qua mạng.

Ví dụ chạy từng bước: bạn thêm cấu hình bên dưới vào Claude Desktop rồi mở lại app.

// claude_desktop_config.json — cấu hình MCP server cho Claude Desktop
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/you/projects"]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "<YOUR_TOKEN>" }
    }
  }
}
  1. Claude Desktop đọc khóa mcpServers, mỗi mục là một server (filesystem, github).
  2. Với mỗi mục, app chạy lệnh command kèm args. Ví dụ: npx -y @modelcontextprotocol/server-filesystem /Users/you/projects. Đối số cuối là thư mục server được phép đọc.
  3. env là biến môi trường chỉ truyền cho tiến trình của server đó (ở đây là token GitHub). Đừng commit token thật.
  4. Cả hai server chạy bằng stdio, nên đây là hai server local.
Thực tế 11/2026 Đặc tả MCP bản 2025-11-25 liệt kê hai transport chuẩn: stdio và Streamable HTTP; Streamable HTTP thay thế transport HTTP+SSE của bản 2024-11-05. Đề thi theo khóa Academy nên vẫn nhắc “SSE hoặc StreamableHTTP” cho server remote. Nguồn: MCP spec, Transports.

Viết MCP server bằng Python SDK: FastMCP là lớp trợ giúp trong SDK, bạn chỉ cần viết hàm Python thường rồi gắn decorator (dòng bắt đầu bằng @) để biến hàm đó thành tool, resource hoặc prompt.

from mcp.server.fastmcp import FastMCP
from pydantic import Field

mcp = FastMCP("Weather Service")

@mcp.tool()
def get_weather(
    city: str = Field(description="The city name to get weather for, e.g. 'San Francisco'"),
    units: str = Field(default="celsius", description="Temperature units: 'celsius' or 'fahrenheit'")
) -> dict:
    """Get current weather conditions for a city."""
    return fetch_weather_api(city, units)

@mcp.resource("weather://current/{city}")
def get_current_weather_resource(city: str) -> str:
    """Current weather as a readable resource."""
    data = fetch_weather_api(city)
    return f"Weather in {city}: {data['temp']}°C, {data['condition']}"

@mcp.prompt()
def weather_analysis_prompt(city: str, days: int = 7) -> str:
    """Generate a weather analysis prompt."""
    return f"Analyze the {days}-day weather forecast for {city} and suggest activities."

if __name__ == "__main__":
    mcp.run()

Đọc từng khối của đoạn code trên:

  • FastMCP("Weather Service") tạo server tên “Weather Service”.
  • @mcp.tool() biến get_weather thành tool. Tên hàm là tên tool, docstring là mô tả, Field(description=…) là mô tả từng tham số. Claude đọc ba thứ này để biết khi nào và gọi thế nào.
  • @mcp.resource("weather://current/{city}") tạo resource có URI mẫu; {city} được điền khi đọc.
  • @mcp.prompt() tạo prompt mẫu có tham số city và days.
  • mcp.run() chạy server (mặc định qua stdio) để client kết nối.
Thực tế 11/2026 Khóa Academy (và ví dụ trên) dùng tên FastMCP (from mcp.server.fastmcp import FastMCP) của Python SDK mcp bản 1.x. Quickstart chính thức hiện hành đã đổi sang lớp MCPServer: from mcp.server import MCPServer, mcp = MCPServer("weather"); cách gắn @mcp.tool() và mcp.run(transport="stdio") vẫn như cũ. Với server stdio, đừng print() ra stdout (làm hỏng JSON-RPC), hãy log ra stderr. Nguồn: MCP Docs, Build an MCP server.

2.3 Resources: Direct và Templated (Bài 4)

Hình dung đời thường
Direct giống một địa chỉ cố định: “Tủ hồ sơ số 1”, lúc nào mở cũng ra cùng một tủ. Templated giống phiếu có chỗ trống: “Hồ sơ của nhân viên số ___”. Bạn điền số vào thì ra hồ sơ đúng người.

Direct resource: URI cố định, dùng cho dữ liệu tĩnh hoặc danh sách.

@mcp.resource("config://app/settings")
def get_app_settings() -> dict:
    """Current application settings."""
    return load_settings_from_file()

Templated resource: URI có parameter, dùng cho dữ liệu động theo ID.

@mcp.resource("users://{user_id}/profile")
def get_user_profile(user_id: str) -> dict:
    """Get user profile by ID."""
    return db.users.find_one({"id": user_id})

Client list resources qua ListResources request, đọc bằng ReadResource request với URI cụ thể.

Ví dụ chạy từng bước với resource templated:

  1. Client gửi ListResources để biết server có gì. Server trả mẫu users://{user_id}/profile.
  2. Client chọn ID cụ thể, ví dụ 42, và gửi ReadResource với URI users://42/profile.
  3. Server khớp URI với mẫu, gán user_id = "42", chạy get_user_profile và trả dữ liệu.

2.4 MCP Client Integration với Claude API (Bài 6–7)

Hình dung đời thường
Bạn là người phục vụ bàn. Bạn cầm thực đơn của bếp (list_tools), đưa cho khách (Claude). Khách chọn món (tool_use), bạn chạy vào bếp đặt món (call_tool), nhận món rồi bưng lại cho khách (tool_result). Claude không tự vào bếp; code của bạn đứng giữa.

Dùng Anthropic SDK để connect tới MCP server từ code:

import anthropic
from anthropic.lib.mcp import MCPClient

mcp_client = MCPClient()

async with mcp_client.connect_stdio("python", ["weather_server.py"]) as session:
    # List available tools từ MCP server
    tools = await session.list_tools()
    print([t.name for t in tools.tools])  # ["get_weather"]

    # Call tool trực tiếp
    result = await session.call_tool("get_weather", {"city": "Tokyo"})

    # Hoặc dùng với Claude Messages API
    mcp_tools = [{"type": "mcp_toolset", "mcp_server_name": "weather"}]
    response = client.beta.messages.create(
        model="claude-opus-5",
        mcp_servers=[{
            "type": "stdio",
            "command": "python",
            "args": ["weather_server.py"],
            "name": "weather"
        }],
        tools=mcp_tools,
        betas=["mcp-client-2025-11-20"],
        messages=[{"role": "user", "content": "What's the weather in Paris?"}]
    )
Beta header bắt buộc: betas=["mcp-client-2025-11-20"] khi dùng MCP với Claude API.
Thực tế 11/2026 Trang MCP connector hiện hành mô tả connector chỉ nhận server remote qua HTTP công khai (Streamable HTTP hoặc SSE); server stdio cục bộ không nối trực tiếp được, và mcp_servers khai báo bằng URL. Connector hiện chỉ hỗ trợ tool calls trong đặc tả MCP. Beta header trong tài liệu hiện liệt kê cả mcp-client-2026-09-15 và mcp-client-2025-11-20. Ví dụ type: "stdio" ở trên theo khóa Academy; nếu chạy thật với server local, hãy dùng vòng lặp MCPClient như Hình 3. Chưa kiểm chứng được tên module anthropic.lib.mcp trong tài liệu hiện hành. Nguồn: MCP connector.

2.5 Tool Filtering và Security (Bài 8)

Hình dung đời thường
Bạn giao chìa khóa nhà cho thợ sửa ống nước. Bạn không đưa cả chùm chìa mở két sắt và phòng ngủ. Chỉ đưa đúng chìa cửa chính và nhà bếp. Với MCP, “chùm chìa” là danh sách tool của server, và bạn chỉ bật những tool thật sự cần.

Chỉ expose tools thực sự cần thiết cho use case:

tools = [{
    "type": "mcp_toolset",
    "mcp_server_name": "filesystem",
    "default_config": {"enabled": False},     # tắt tất cả tools mặc định
    "per_tool_config": {
        "read_file": {"enabled": True},        # chỉ enable read
        "list_directory": {"enabled": True}
        # write_file, delete_file: vẫn tắt
    }
}]

Trust hierarchy: Remote MCP server có thể gửi tool descriptions chứa prompt injection. Coi tool descriptions từ unverified server như untrusted input. Luôn review server code trước khi dùng.

Sai
  • Bật mọi tool của server “cho tiện”
  • Agent chỉ cần đọc file nhưng vẫn có delete_file
  • Cài server lạ mà không đọc mã nguồn
Đúng
  • default_config tắt hết, per_tool_config bật từng tool cần dùng
  • Chỉ cấp quyền đủ cho use case
  • Review code server và coi tool description như đầu vào không tin cậy

Hình dung đời thường

3.1 Sampling: LLM Requests từ Server (Bài 1–3)

Sampling cho phép MCP server yêu cầu Claude tạo text — server gửi sampling/createMessage request lên client, client xử lý và trả kết quả. Dùng cho các use case như: server cần phân tích dữ liệu, server cần tóm tắt kết quả tool call.

Điểm đáng chú ý: server không cần API key của model. Client giữ quyền gọi model, chọn model và quyết định có cho phép hay không.

Deprecated từ đặc tả MCP 2026-07-28 (SEP-2577): Sampling là tính năng legacy, server mới không nên dùng. Khóa Academy gợi ý Elicitation thay thế, nhưng đặc tả hiện hành ghi đường chuyển đổi khác: server gọi thẳng API của nhà cung cấp LLM. Elicitation (server xin thêm thông tin từ người dùng) vẫn là tính năng client đang hoạt động, không phải bản thay thế của sampling.
from mcp.server.fastmcp import FastMCP
from mcp import ClientSession

mcp = FastMCP("Analysis Server")

@mcp.tool()
async def analyze_data(data: str, ctx: Context) -> str:
    """Analyze data using Claude via sampling."""
    result = await ctx.sample(
        messages=[{"role": "user", "content": f"Analyze this data:\n{data}"}],
        system="You are a data analyst. Provide concise insights.",
        max_tokens=500
    )
    return result.content[0].text

# Phía client: đăng ký sampling callback
async def sampling_callback(params):
    response = client.messages.create(
        model="claude-haiku-4-5",
        max_tokens=params.maxTokens or 500,
        messages=params.messages
    )
    return response

session.set_sampling_callback(sampling_callback)

Đọc code theo hai phía: phía server, tool analyze_data gọi ctx.sample(...) thay vì tự gọi API. Phía client, sampling_callback nhận yêu cầu đó và gọi Claude (ở đây là claude-haiku-4-5) rồi trả kết quả.

Thực tế 11/2026 Đặc tả MCP bản 2026-07-28 (bản hiện hành) deprecate cùng lúc Roots, Sampling và Logging (SEP-2577), và deprecate Dynamic Client Registration của OAuth (PR #2858, thay bằng Client ID Metadata Documents). Tính năng deprecated vẫn hoạt động và còn trong đặc tả ít nhất mười hai tháng (sớm nhất bị gỡ ở bản phát hành từ 2027-07-28), nhưng triển khai mới không nên dùng. Đường chuyển đổi đặc tả ghi: Sampling → tích hợp thẳng API nhà cung cấp LLM; Logging → log ra stderr (stdio) hoặc dùng OpenTelemetry. Bản này cũng bỏ kiểu server tự gửi request: sampling/createMessage giờ nằm trong InputRequiredResult (mẫu Multi Round-Trip Requests) và client trả lời bằng cách gửi lại request gốc kèm inputResponses. Elicitation không bị deprecate. Đặc tả vẫn ghi sampling nên luôn có người duyệt (human in the loop). Đề thi theo khóa Academy có thể vẫn hỏi Sampling như một capability. Nguồn: MCP spec, Changelog 2026-07-28, MCP spec, Sampling, Deprecated features registry.

Sampling
Server nhờ client gọi LLM giúp để tạo text.
Callback
Hàm bạn đăng ký sẵn để thư viện gọi lại khi có sự kiện, ở đây là khi server xin sampling.
Elicitation
Server xin thêm thông tin từ người dùng, khác với sampling là xin text từ LLM.
Human in the loop
Có người xem và duyệt trước khi hành động tiếp tục.

3.2 Roots: File Access Boundaries (Bài 4–6)

Hình dung đời thường
Thẻ ra vào khách của tòa nhà ghi rõ: “được vào tầng 3 và 4”. Bảo vệ kiểm thẻ mỗi khi bạn bấm thang máy. Roots là tấm thẻ đó: client nói với server “bạn chỉ được làm việc trong những thư mục này”.

Roots cho phép client khai báo danh sách URI (thường là file paths) mà server được phép truy cập. Server không được tự động truy cập ngoài roots — đây là cơ chế bảo vệ filesystem.

Deprecated từ đặc tả MCP 2026-07-28 (SEP-2577). Đoạn trên là cách khóa Academy trình bày. Đặc tả hiện hành nói roots chỉ là hướng dẫn mang tính thông tin, không phải cơ chế kiểm soát truy cập: giao thức không ép server ở trong roots. Ranh giới chỉ có hiệu lực khi chính server tự kiểm tra (như is_path_allowed() bên dưới) hoặc khi host/OS giới hạn quyền. Server mới nên nhận thư mục, file qua tham số tool, URI resource hoặc cấu hình server thay vì Roots.
from mcp.server.fastmcp import FastMCP
from pathlib import Path

mcp = FastMCP("File Server")

@mcp.tool()
async def read_file(path: str, ctx: Context) -> str:
    """Read a file from an allowed path."""
    roots = await ctx.get_roots()

    def is_path_allowed(file_path: str, roots) -> bool:
        p = Path(file_path).resolve()
        for root in roots:
            root_path = Path(root.uri.replace("file://", "")).resolve()
            try:
                p.relative_to(root_path)
                return True
            except ValueError:
                continue
        return False

    if not is_path_allowed(path, roots):
        raise ValueError(f"Path {path} is outside allowed roots")

    return Path(path).read_text()

Client khai báo roots:

session = await client.connect()
await session.update_roots([
    {"uri": "file:///home/user/projects/", "name": "Projects"}
])
Cốt lõi. Roots khai báo “vùng được phép”. Việc kiểm tra trước mỗi lần đọc (is_path_allowed()) nằm trong code của server.
Thực tế 11/2026 SEP-2577 đánh dấu Roots deprecated (cùng Sampling và Logging) từ đặc tả bản 2026-07-28; vẫn dùng được ít nhất mười hai tháng. Đường chuyển đổi đặc tả ghi: truyền thư mục hoặc file qua tham số tool, URI resource hoặc cấu hình server. Đặc tả mô tả roots là “informational guidance rather than an access-control mechanism”, giao thức không ép server ở trong roots, nên server vẫn phải tự kiểm tra đường dẫn. uri của root phải là URI file://. Ở bản 2026-07-28, server xin danh sách bằng roots/list đặt trong InputRequiredResult (client trả lời khi gửi lại request gốc), và notification notifications/roots/list_changed đã bị bỏ (bản 2025-11-25 còn dùng nó cùng cờ listChanged). Khóa Academy, và đề thi soạn theo khóa, vẫn coi Roots là cách giới hạn file access; khi làm đề cứ chọn theo cách đó, khi thiết kế thật thì đừng coi Roots là lớp bảo mật. Nguồn: MCP spec, Roots, MCP spec, Changelog.
Thuật ngữ
Root
Một URI (thường file://…) đánh dấu vùng server được làm việc.
Path traversal
Dùng ../ hoặc symlink để chui ra ngoài thư mục được phép.
resolve()
Đổi đường dẫn thành dạng tuyệt đối, đã gỡ .. và symlink.

3.3 StreamableHTTP Transport (Bài 7–9)

Hình dung đời thường
Gọi hotline: mỗi cuộc gọi được trả lời độc lập bởi bất kỳ nhân viên trực nào, không cần nhớ bạn là ai (stateless). Quán nào cũng thêm được nhân viên khi đông khách. Ngược lại, đường dây riêng giữa hai phòng giữ liên lạc liên tục nhưng khó mở rộng.

Transport mới thay thế SSE (Server-Sent Events). Ưu điểm: stateless (mỗi request độc lập, dễ scale), hoạt động tốt với HTTP/2, proxies thân thiện hơn.

from mcp.server.fastmcp import FastMCP
from starlette.applications import Starlette
import uvicorn

mcp = FastMCP("HTTP Server", stateless_http=True)   # stateless mode

# Optional: trả JSON thay vì SSE stream cho simple responses
@mcp.tool(json_response=True)
def simple_lookup(key: str) -> dict:
    """Fast lookup that returns JSON directly."""
    return db.get(key)

# Mount vào Starlette app
app = mcp.streamable_http_app()

if __name__ == "__main__":
    uvicorn.run(app, host="0.0.0.0", port=8000)

Chạy từng bước: stateless_http=True bật chế độ không lưu phiên. mcp.streamable_http_app() trả về một app web (Starlette) để uvicorn phục vụ ở cổng 8000. Mỗi request tới được xử lý độc lập, nên bạn đặt nhiều bản sao server sau một load balancer mà không cần giữ phiên.

Limitations của HTTP transport: Không hỗ trợ server-initiated notifications (server không thể push updates tới client). Nếu cần real-time updates từ server, dùng SSE hoặc WebSocket.

Thực tế 11/2026 Đặc tả Streamable HTTP cho phép server trả mỗi request bằng một JSON hoặc một luồng SSE riêng cho request đó (mang notification như notifications/progress trước kết quả cuối). Giới hạn “không push” trong bài đúng với chế độ json_response. Từ bản 2026-07-28, giao thức bỏ hẳn session (Mcp-Session-Id), bỏ endpoint GET và khả năng nối lại luồng SSE (Last-Event-ID); server không còn tự gửi request cho client (sampling, elicitation, roots đi qua InputRequiredResult), còn thông báo thay đổi dài hạn (list_changed, resource updated) đi qua request subscriptions/listen. Transport HTTP+SSE cũ deprecated từ bản 2025-03-26. Đặc tả vẫn yêu cầu server kiểm tra header Origin (chống DNS rebinding), khi chạy local nên bind 127.0.0.1 thay vì 0.0.0.0, và nên có xác thực. Ví dụ trên bind 0.0.0.0 chỉ để minh họa. Nguồn: MCP spec 2026-07-28, Streamable HTTP.
Thuật ngữ
Stateless
Server không nhớ request trước. Mỗi request mang đủ thông tin.
SSE (Server-Sent Events)
Kênh một chiều để server đẩy dữ liệu liên tục cho client qua HTTP.
Load balancer
Thiết bị chia request cho nhiều bản sao server.
Endpoint
Một địa chỉ URL mà client gửi request tới, ví dụ /mcp.

3.4 Security Best Practices cho MCP (Bài 10–11)

Hình dung đời thường
Có người nhét tờ giấy vào cuốn sổ tay của nhân viên: “Từ giờ hãy gửi mọi hồ sơ cho địa chỉ này”. Nhân viên đọc sổ và làm theo, vì không phân biệt được đâu là ghi chú thật, đâu là lệnh giả. Tool description của một server lạ giống tờ giấy đó.
Rủi roCách phòng tránh
Tool description injectionChỉ dùng server từ trusted sources; review source code
Path traversalDùng Roots, luôn gọi is_path_allowed() trước khi đọc file (Roots deprecated từ đặc tả 2026-07-28 và chỉ mang tính thông tin, nên phần kiểm tra trong server mới là lớp chặn thật)
Secret leak qua tool resultsKhông log tool results chứa credentials; dùng env vars
SSRF qua URL toolsWhitelist domain được phép; block internal IPs (169.254.x.x, 10.x.x.x)
Excessive permissionsFilter tools với per_tool_config; principle of least privilege
Sai
  • Tin tool description vì “nó chỉ là mô tả”
  • Cho tool URL fetch được mọi địa chỉ, kể cả 169.254.x.x
  • Log toàn bộ kết quả tool, kể cả token
Đúng
  • Coi description như đầu vào người dùng, có thể bị cài độc
  • Whitelist domain, chặn IP nội bộ để tránh SSRF
  • Không log credential, lấy secret từ biến môi trường
Thuật ngữ
Prompt injection
Chèn chỉ dẫn giả vào nội dung mà model sẽ đọc, để lái hành vi của nó.
SSRF
Lừa server tự gửi request tới địa chỉ nội bộ mà kẻ tấn công không truy cập trực tiếp được.
Least privilege
Chỉ cấp đúng quyền cần dùng, không hơn.
Quy tắc vàng: Treat MCP tool descriptions như user input — có thể bị inject bởi malicious server operator. Claude không phân biệt được nội dung tool description hợp lệ với instruction injection.

4. Lưu ý ôn thi

Hình dung đời thường
Trong nhà hàng, ai là người “khởi xướng” khác nhau. Bếp tự quyết định nấu thêm món gì (Claude gọi tool). Quản lý lấy sẵn nguyên liệu vào bếp (app nạp resource). Khách chọn combo trong thực đơn (user chọn prompt). Đề thi hay hỏi đúng chỗ “ai bấm nút”.
CCAR-F D2 (18%): Nắm vững 3 MCP capabilities (tools/resources/prompts), sự khác biệt local vs remote transport, cách filter tools với per_tool_config, và khi nào dùng Roots để giới hạn file access (khóa Academy vẫn dạy Roots; đặc tả MCP 2026-07-28 đã deprecate Roots, Sampling, Logging).
CCDV-F D8 (10,6%): Biết cú pháp khai báo mcp_servers + betas header, cách MCPClient list_tools và call_tool, hiểu trust hierarchy của MCP server descriptions.
Phân biệt: Tool use = Claude tự quyết định gọi khi nào (model-initiated). Resources = client/host request chủ động (application-controlled). Prompts = user chọn trong UI (user-initiated). Sampling = server request Claude tạo text (deprecated).

  • Roots chỉ mang tính thông tin, server tự kiểm tra đường dẫn; Roots cũng deprecated 2026-07-28
  • Cần betas=["mcp-client-2025-11-20"] khi dùng MCP với Claude API
