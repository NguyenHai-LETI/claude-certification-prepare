**OLD**

      CCAO-F: D3
    stem: A user has memory turned on and works in two Projects, A and B. While chatting in Project B, which memory can Claude use?

      - Only Project B's memory, with nothing from outside Project B

      CCAO-F: D3

    options:
      - Project B's memory alone, kept separate from every other chat
      - All memory from every Project plus all chats outside Projects
      - Project B's memory plus memory from chats outside Projects
      - Memory from chats outside Projects, but not Project B's own memory
    answer:
      - C
